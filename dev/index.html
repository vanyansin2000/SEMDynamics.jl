SEMDynamics.jl

SEMDynamics.jl 提供地月受限多体动力学数值计算工具，包括 CR3BP、BCR4BP、事件检测、 坐标变换、轨迹可视化和周期轨道计算。

安装

在包注册前，可直接从仓库安装：

using Pkg
Pkg.add(url="https://github.com/vanyansin2000/SEMDynamics.jl")

注册后，可使用标准包安装命令：

using Pkg
Pkg.add("SEMDynamics")

最小示例

using SEMDynamics

aux = Bcr4bp_Aux()
state = [0.8, 0.1, 0.02, -0.03]
derivative = similar(state)
cr3bp_eqm!(derivative, state, aux, 0.0)
